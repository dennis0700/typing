# typing

一个面向儿童的桌面打字练习应用，使用 Rust + [Slint](https://slint.dev/) 构建。

## 功能特性

- **分阶段课程序列**：内置 14 门课程，按"基准键位 → 上排 → 下排与字母全集 → Shift 组合符号 → 词语 → 句子"的顺序递进，每门课程设有可量化的解锁条件（准确率、完成时长、练习次数）。
- **多学员档案**：单台设备最多支持 10 个学员档案，各自独立记录学习进度，互不覆盖；支持创建、重命名、重置进度与删除。
- **虚拟键盘与手指分区提示**：练习时高亮下一个待输入字符对应的键位，并提示应使用的手指分区，帮助建立正确的指法习惯。
- **实时反馈**：统计正确率与 WPM（每分钟字数），练习结束后与历史最佳成绩对比展示；连续输错时给予鼓励提示，连续错误过多时展示正确答案。
- **奖励反馈**：课程完成时展示庆祝动画与徽章等正向激励。
- **按键音效**：击键时播放实时合成的机械键盘音效（正确/错误音色不同），无需打包音频资源文件。
- **本地持久化**：学员档案以 JSON 形式保存在本机文件系统（macOS：`~/Library/Application Support/typing/profiles/`），读写失败不会导致数据丢失或崩溃。

## 环境要求

- Rust（见 [`rust-toolchain`](https://www.rust-lang.org/tools/install) 或直接安装最新 stable 版本）
- macOS（当前已验证的平台；Slint 本身支持 Windows/Linux，但本仓库尚未针对这些平台做验证与打包）

## 构建与运行

```sh
# 调试构建并运行
cargo run

# 发布构建
cargo build --release
```

构建产物位于 `target/release/typing`。

## 测试

```sh
cargo test --release
```

## 开发期调试环境变量

以下环境变量仅用于本地开发调试，不属于产品功能：

| 变量 | 作用 |
|---|---|
| `TYPING_TRACE=1` | 启用调试追踪日志（输出到 stderr） |
| `TYPING_DEV_STORE_DIR=<path>` | 覆盖档案存储目录，避免调试数据污染真实学员档案 |
| `TYPING_DEV_AUTOSTART=1` | 启动时自动创建/选择一个调试档案并直接进入课程序列界面 |
| `TYPING_MUTE=1` | 关闭按键音效 |

## 项目结构

```text
src/
├── domain/      # 纯领域逻辑：课程定义、键位布局、练习文本生成、统计计算、字符匹配
├── app_state/   # 全局状态机：AppController 事件分发、课程/练习/档案会话状态
├── storage/     # 学员档案的本地持久化（JSON 读写）
├── ui/          # Slint 界面定义（.slint 文件）
├── ui.rs        # Rust 与 Slint 之间的回调桥接层
├── audio.rs     # 按键音效合成与播放
└── main.rs      # 应用入口
```
